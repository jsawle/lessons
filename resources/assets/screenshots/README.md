Pictures of each lesson's web map at its opening view, used as `map.image` on the lesson pages (https URL on GitHub Pages, with alt text that describes the picture without giving answers). One per lesson, named `<lesson id>.jpg`, 1200 x 675 px, with the map's attribution line.

They are taken by the **Map pictures** workflow (`.github/workflows/map-screenshots.yml`, which runs `resources/tools/map-screenshots.mjs` and `resources/tools/map-shot.html`): run it from the Actions tab, naming lesson ids or leaving the box empty for every lesson, or push to a branch named `map-shots`. It commits the pictures and `report.json`, which lists each map's layers, whether each is visible and loaded, and any errors. Check a new picture and the report against the lesson file before using it, and take the picture again whenever a web map's layers, symbols or opening view change.
