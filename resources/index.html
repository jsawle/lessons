How this works

  1. One file per lesson. Each lesson is a single file in resources/lessons. The page, the Word student sheets (English and Spanish), the how-to links and the summary for AI tools are all made from it, so they can't drift apart.
  2. Shared settings in one place. Hub links, the MapMaker app, tool names and sheet wording live in resources/site.json. Change them once and every lesson follows.
  3. A checker on every change. The same checker runs on the page (problems show in a red banner) and on GitHub for every push, so a broken file is caught before anyone sees it.
  4. Versions and review. Each lesson has its own content version, status (draft, reviewed, published), review record and known-issues list, shown on the page.
  5. Route to the Hub. The same file can later create the Hub page and the Word items in ArcGIS Online by script, so the Hub never needs hand editing.
