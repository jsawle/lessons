How this works

  1. One file per lesson. Each lesson is a single file in resources/lessons. The page, the Word student sheets (English and Spanish), the how-to links and the lesson's entry in Vera's knowledge file are all made from it, so they can't drift apart.
  2. Settings in two places. Shared wording, units, tool names and the rubric live in resources/site.json; the Atlas app, the Hub, the AI assistant, the licence and the product names live in resources/mapmaker-lessons.json. Change them once and every lesson follows.
  3. A checker on every change. The same checker runs on the page (problems show in a red banner) and on GitHub for every push, so a broken file is caught before anyone sees it.
  4. Versions and review. Each lesson has its own content version, status (draft, reviewed, published), review record and known-issues list, shown on the page.
  5. Vera knows every lesson. Each lesson page opens Vera with that lesson named, so teachers can ask for different questions. Vera works from a knowledge file made from the lesson files; download it below and upload it in Copilot Studio.
  6. Hub pages from the same files. The files also build each lesson's Hub page (see the Hub preview). A notebook publishes them, with the Word sheets as ArcGIS Online items, to the demo Hub site, so the Hub never needs hand editing.
